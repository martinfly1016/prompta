## Part F — R6 任务族难度矩阵沉淀（`ff0ef02`）

PicoTrex batch 验证了一个重要观察：

| 任务族 | 难度 | R6 触发 |
|---|---|---|
| 🟢 **整图风格化**（figure/plushie/sculpture/OOTD/isometric/sticker/miniature/marble） | 稳定 | **不需要**（整图重画就是目标） |
| 🟢 **局部身份保持**（hairstyle/expression/face-retouch/id-photo） | 稳定 | 不需要 |
| 🔴 **保持身份 + 改环境**（colorize/outfit-swap/bg-replace/remove-bystanders） | 风险 | **必加** |
| 🔴 **透明 PNG**（bg-remove-transparent） | 不支持 | 改用 ChatGPT |

**Key insight 写入 SKILL.md**: 「整图风格化」乍看像「大范围编辑」，其实是 **更安全** 的任务族 — 区别在于用户预期是「我变成不同的视觉表达」（保留 identity recognizability 而非 photo realism），而 colorize/outfit-swap 是「场景变了人不变」，需要照片真实感锁身份，反而是 Gemini 弱项。

## Part G — `effect` 优先卡片缩略图（`808da6b`）

用户反馈：首页「最新のプロンプト」grid 显示 4 张 photo-edit prompt 卡片，但都是同一张 source 肖像图。

**根因**: PromptCard 用 `sampleAfterUrl || images[0]?.url` 回退到 `images[0]`，photo-edit prompt 的 `images[0]` 是 imageType='original'（即 Before），所以全是同一张源照片。

**修复**: NormalizedPrompt.images 加 `imageType` 字段 + PromptCard 优先 `find(i => i.imageType === 'effect')`。所有 photo-edit prompt 卡片自动改显 After 图。

2. 跑 `gsc-query.ts --mode=top-queries --days=7` 看 Top 30 query
3. **交叉检查**: 高流量 query 着陆页是否包含**对应 query 意图相符的具体内容**
4. **特别关注**: bounce > 75% 的高流量页 = 高概率内容错位
5. 如发现错位（如身長差案例）→ 3-phase 修复（内容补 / tag 修 / guide 建）

### 2. 高流量页面用户行为质量信号

需要常规监控的指标 vs 页面状态：

| 指标 | 健康线 | 报警线 | 含义 |
|---|---|---|---|
| Bounce rate | < 60% | > 80% | > 80% 强烈暗示内容错位 |
| Avg session duration | > 60s | < 20s | < 20s 等于用户秒走 |
| Pages per session | > 1.5 | < 1.1 | < 1.1 等于完全无内链跳转 |
| CTR from SERP | > 5% | < 1% | 低 CTR 暗示 title/desc 不吸引 |

发现错位的 fix 优先级：
1. tag 关联修（最快，DB 直改）
2. seoIntro / 内容补齐
3. 拆分新 guide
4. 整页重写

### 3. 多 provider AI 工具的 silent failure 防御

每个新 provider 必查 3 件事：
1. **size guard** — 真实生成 vs safety blank 的字节差（fal: 100KB+ vs 20KB-）
2. **content guard** — text-only response 的 fallback（Gemini 已有，OpenAI 已有，新加的要补）
3. **log + refund** — silent fail 必须 throw 触发上游 refund 链路

### 4. 营销文案 vs 代码实现的时序

不允许营销文案领先代码 > 24h。如果非要拆分：
- commit message 必须显式 flag「marketing copy ahead of code, follow-up: implement X」
- 24h 内必须 ship 代码层
- 法律 / 合规 文案（如有効期限）不能拆分
