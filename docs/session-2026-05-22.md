## 关键 feedback / 决策

- **GSC index audit 应该例行做**（季度或半年）— 一次发现 4 个 unknown URL / 1 个 canonical 劫持 / 24 条 crawled-not-indexed 系统性问题。`_inspect-sitemap-coverage.ts` 是 reusable tool，每次跑 5-7 min
