## Part C — PromptExecutor 全套（commit 7, 8, 13-20）

### 架构
```
src/lib/image-providers/        ← Provider Abstraction Layer
├── types.ts                    ← ImageProvider 接口
├── gemini-image.ts             ← Gemini 3.1 Flash Image ($0.039, 5 credit)
├── openai-image.ts             ← GPT Image 1 ($0.04, 5 credit)
├── gemini-text.ts              ← Gemini 2.5 Flash text ($0.003, 1 credit)
└── registry.ts                 ← drop-a-file 注册 + recommendForPrompt

src/app/api/prompt/execute/     ← API endpoint
src/components/prompt/PromptExecutor.tsx       ← 3-mode (text/image-gen/image-edit)
src/components/prompt/PromptInteractive.tsx    ← params panel + executor 联动 wrapper
src/components/credits/CreditPurchaseModal.tsx ← 购入確認浮层
src/components/credits/TopUpCreditsButton.tsx  ← /account top-up CTA
```

### Auto Dispatch 规则
| Prompt 类型 | Mode | 默认 Provider | Credit |
|---|---|---|---|
| `category=photo-edit` | image-edit（需上传源照片）| Gemini | 5 |
| `category∈{writing,programming,business,education}` 或 `tool∈{chatgpt,claude}` | text | Gemini Flash text | 1 |
| 其他（hairstyle/clothing/anime/creative/...）| image-gen | Gemini Flash Image（可切 ChatGPT）| 5 |

### 保障机制
- **Race condition**: `spendCredits` WHERE balance >= n（原子）
- **失败退款**: `refundCredits`（不动 totalEarned / lastPurchase）— commit `a74d3aa` 修
- **防刷**: 5 req / 5 sec / anon
- **重复请求**: 60s in-memory cache
- **结果持久化**: `GenerationOutput` 表（commit `44b1d24`）+ `/account` gallery 显示

### 详情页接入
- `<PromptInteractive>` wrapper：参数面板调参 → ref 保存最新 rendered → PromptExecutor execute() 时读取
- Out-bound「ChatGPTで試す / Geminiで試す」按钮也用 rendered content

### UX 修复（commits 8-20 大头）

| Bug | 现象 | 修复 |
|---|---|---|
| Google-only sign-in | 「実行には Google サインインが必要」太窄 | `signIn(undefined)` 跳 NextAuth picker |
| Welcome 50 太慷慨 | 新用户拿 10 张图免费 | 改 15 = 3 张图（成本回归 $0.12）|
| Photo-edit 无预览 | 上传后只显「✓ 写真が選択されました」 | 192×192 缩略图 + 替换/删除按钮 |
| Refund 虚增 totalEarned | `/account` 显示 累計獲得 20 不一致 | `refundCredits()` 不动 totalEarned |
| 下载按钮跳页 | 跨域 `<a download>` 失效，同 tab 跳到图 | `fetch` blob → `URL.createObjectURL` |
| 不显示模型 | 不知道扣 5 credit 跑哪家 | 「使用モデル: ✨ Gemini」badge |
| 購入跳工具页 | 点购入跳 personal-color | `returnTo` 参数 + Stripe Checkout 直跳 |
| 突然跳 Stripe | 没确认就跳到付款页 | **CreditPurchaseModal**（明细 + 购入按钮）|
